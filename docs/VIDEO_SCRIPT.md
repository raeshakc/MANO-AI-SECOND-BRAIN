# Under-three-minute MANO video script

Video must show the actual application working, and should be publicly viewable on YouTube. Target 2:35–2:50.

**0:00–0:20 — Hook:** “Students are balancing classes, shifts, clubs, internships and life. What if an assistant could connect it all and help us take the next step?” Show MANO's interface.

**0:20–0:50 — Real context:** Click **Load fictional student week**. Show deadlines and actual overlap between a shift and a meeting. Explain that this conflict is identified deterministically.

**0:50–1:30 — Live agent:** Click **Rescue my week** and show a genuine NVIDIA Nemotron response through Nebius. Narrate the exact proposal, and check its accuracy.

**1:30–1:58 — Action with approval:** Approve one task or time block, show it saved, export an `.ics` calendar reminder. Mention that the file must be imported; don't claim notification delivery.

**1:58–2:22 — Recall:** Click **Yesterday's recap** to show earlier fictional conversation recalled. Explain that public-demo memory is session scoped; secure per-user persistent storage is future work.

**2:22–2:48 — Architecture and why:** Show or narrate Nemotron 3 Super -> Nebius Token Factory -> Streamlit/SQLite -> validated actions. Finish: “MANO is designed to help students turn mental overload into clear, approved steps.”

**Recording checklist:** test all steps live before recording; no API keys onscreen; keep screen visible, microphone clear, and video publicly accessible.
